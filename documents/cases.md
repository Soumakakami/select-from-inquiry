## ケースを追加する手順

1. **データを仕込む**：`src/datagen.js` の「scripted cases」に、そのケース用のユーザー（`mkUser`）、キャラ（`mkChar`）、ログ（`login` / `charlog` / `itemlog` / `cur` / `purchase` / `err`）を追加する。
   - 決め手のログには最後の引数でキー（例 `'c8_xxx'`）を付ける。採番後の ID が `keys.c8_xxx` に入る。
   - ノイズとぶつからないよう、必要なら `blackout`（期間中ノイズを生成しない）、`noPayments`、`noTrades`、`noBigGold`、`scriptedOnly`、`activeUntil` を使う。
   - 名前を使うキャラは `RESERVED` に加え、ランダム生成と重複しないようにする。
2. **ケースを定義する**：`src/game.js` の `CASES` に1件追加する。
   - `no`、`label`、`received`（JST）、`user`、`world`、`category`、`body`、`note`
   - `options`（4択）と `answer`
   - `evidence`：log_id で採点するなら `key`、それ以外なら `accept`（入力を受け取って true/false を返す関数。`norm()` で全角半角や空白を正規化）
   - `hints`（3つ）、`reply`（ユーザーへの回答文）、`reaction`、`explain`、`model`（模範SQL）
3. **確認する**：`npm run verify` に模範SQLを足して結果を確認 → `npm run build` → `npx serve docs` で実際に解く。
4. 満点や称号のしきい値（`RANKS`）は件数に合わせて見直す。
